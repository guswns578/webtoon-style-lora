# 평가 프로토콜

생성 결과를 하나의 총점으로 판정하지 않고 네 축을 분리합니다.

1. **캐릭터 정체성**: 목표 캐릭터의 얼굴 구조와 가까운가
2. **포즈 보존**: ControlNet 입력의 관절 배치와 화면 구성을 따르는가
3. **선화 스타일**: 원작의 가는 선, 흰 여백, 제한된 회색 분포와 가까운가
4. **생산 적합성**: 색 누출, 얼굴·손 붕괴, 과도한 검정 면적이 없는가

복합점수는 후보 정렬에만 사용합니다. 자동 합격은 각 축의 최소 기준을 모두 통과해야 합니다.

## 1. 캐릭터 정체성: CCIP

생성 이미지에서 가장 큰 얼굴을 검출하고, 캐릭터별 원본 얼굴 레퍼런스와 CCIP 거리를 계산합니다. 각 캐릭터에서 가까운 레퍼런스 3장의 중앙값을 그 캐릭터의 거리로 씁니다.

```
margin = 두 번째 후보 거리 - 목표 캐릭터 거리
```

거리가 낮아도 margin이 작으면, 외형이 비슷한 캐릭터 사이에서 불확실성이 높다는 뜻입니다.

### 원본 도메인 보정 결과 (`pipeline/calibrate_ccip.py`)

| 항목 | 결과 |
|---|---:|
| 캐릭터 | 8명 |
| 정제 얼굴 레퍼런스 | 74장 |
| Leave-one-out Top-1 | 90.54% |
| 동일 캐릭터 거리 중앙값 | 0.0341 |
| 동일 캐릭터 거리 90백분위 | 0.0569 |
| 균형 정확도 최적 임계값 | 0.06335 |
| 최적 임계값의 균형 정확도 | 95.37% |

`0.06335`는 깨끗한 원본 얼굴 기준입니다. 생성 얼굴은 도메인이 달라서, 사람 라벨로 보정하기 전까지 `0.09`를 임시 운영 기준으로 둡니다. 이 값은 이 데이터셋에서 경험적으로 정한 내부 기준이며 일반적인 임계값이 아닙니다.

## 2. 속성 보조 지표: WD EVA02 Large v3

CCIP가 얼굴 구조를 비교한다면, EVA 속성 프로토타입은 성별 표현, 수염, 뾰족귀, 동물귀, 머리 길이 같은 구분 축을 검사합니다 (`pipeline/eva_attribute_identity.py`).

- 원본 74장 leave-one-out 정확도: **83.78%**
- CCIP보다 낮으므로 대체 지표로 쓰지 않습니다.
- CCIP와 EVA가 일치하면 신뢰를 강화하고, 불일치하면 자동 탈락 대신 사람 검수로 보냅니다.

사례: Char_G 전신 후보에서 CCIP는 Char_B를 골랐지만 EVA는 Char_G를 골랐습니다. 이 후보는 `1girl=0.990`, `pointy_ears=0.972`로 핵심 속성을 지키고 있었습니다. 중성적인 원본 표현에서는 CCIP Top-1만으로 실패를 확정하면 안 된다는 근거입니다.

## 3. 포즈 보존: DWPose

목표 포즈와 생성물에서 관절을 다시 검출해 계산합니다 (`pipeline/pose_metrics.py`).

- `coverage`: 목표에서 보인 관절 중 생성물에서도 검출된 비율
- `shape_rmse`: 이동·크기만 정규화한 관절 오차 (화면 방향 보존)
- `composition_rmse`: 캔버스 안 절대 위치·크기 오차
- `pose_score`: 위 셋을 결합한 0~1 점수

회전까지 허용하는 Procrustes 정렬은 옆으로 돌아간 결과를 잘못 보상하므로 쓰지 않습니다. 이 수정으로 한 실패 사례의 점수가 0.566 → 0.422로 내려가 기준(0.45) 아래로 바르게 분류됐습니다.

OpenPose가 관절을 찾지 못하면 "포즈 실패"가 아니라 "포즈 검증 불가"이며 사람 검수로 보냅니다. 입력 포즈 자체도 8관절 미만이면 생성 전에 차단합니다 (`pipeline/validate_controlnet_pose_sources.py`).

## 4. 스타일: CSD + 선화 분포

### CSD

장면 유형별 원작 레퍼런스 5장의 CSD 임베딩 평균을 스타일 프로토타입으로 두고, 생성물과 cosine similarity를 계산합니다. 공개 체크포인트가 논문 수치와 완전히 같지 않을 수 있어 단독 합격 기준으로 쓰지 않습니다.

### 선화 분포

- 검정 / 진한 검정 / 회색 / 흰색 픽셀 비율
- 평균 명도
- 에지 밀도
- 어두운 잉크 마스크의 거리 변환 기반 선 굵기

스타일 점수는 `CSD 40% + 선화 분포 60%`입니다. 최종 산출물은 비파괴 흑백 정규화 후 평가합니다. LPIPS 하나로 스타일을 판단하지 않습니다. 구조가 비슷한 이미지에 유리하고, 스타일과 정체성을 분리하지 못하기 때문입니다.

## 5. 조건부 얼굴 보정

`pipeline/conditional_face_refine.py`

1. 같은 포즈로 여러 시드를 생성합니다.
2. CCIP와 포즈 점수를 계산합니다.
3. 포즈는 충분하지만 정체성이 실패한 후보만 얼굴 마스크 인페인팅으로 보정합니다.
4. denoise `0.32 / 0.42 / 0.52`를 비교합니다.
5. 정체성과 포즈를 모두 통과한 후보만 자동 채택합니다.

후보 선택: 목표 캐릭터가 최근접인 후보 중 `정체성 55% + 포즈 45%` 점수가 가장 높은 것을 고릅니다. 그런 후보가 없으면 최고점 후보를 임시 선택하되 `manual_review_required=true`로 표시합니다.

## 6. 실패 유형별 처리

| 실패 유형 | 처리 |
|---|---|
| 정체성만 실패 | 캐릭터 가중치 조정 또는 얼굴 인페인팅 |
| 포즈만 실패 | ControlNet·캔버스 비율 재시도 |
| 둘 다 실패 | 전체 재생성 후 재평가 |
| 얼굴 검출 실패 | 고해상도 재시도 또는 사람 검수 |
| 포즈 검출 실패 | 사람 포즈 검수 |
| CCIP-EVA 불일치 | 캐릭터 속성 사람 검수 |

## 7. 표정의 시드 견고성

강한 표정은 프롬프트를 지나치게 약하게 만들기보다, 중간 강도로 여러 시드를 생성해 CCIP로 고릅니다 (`pipeline/expression_seed_robustness.py`).

| 캐릭터 / 표정 | 실측 통과율 (4시드) | 95% 확률로 1장 확보에 필요한 N |
|---|---:|---:|
| Char_D angry | 75% | 3 |
| Char_D smile | 75% | 3 |
| Char_A angry | 50% | 5 |
| Char_A smile | 100% | 1 |
| Char_E angry | 100% | 1 |
| Char_E smile | 100% | 1 |

시드가 서로 독립이라는 근사를 쓴 계산이며, 신뢰구간을 위해 시드를 더 늘려야 합니다.

## 8. 자동 합격 규칙 (임시)

1. 목표 캐릭터가 CCIP Top-1
2. CCIP 생성 도메인 거리 `<= 0.09`
3. 포즈가 검출되고 pose score `>= 0.45`
4. 색 누출과 회색·검정 면적이 생산 기준 이내
5. CCIP와 EVA가 크게 불일치하지 않음 (불일치하면 검수)
